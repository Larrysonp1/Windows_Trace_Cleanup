# PowerShell Script to Run Commands

This repository contains a PowerShell script to run "PC_Clean_Up".

## How to Download and Run

1. **Download the Script:**
   - Go to the [PC_Clean_Up.ps1](./PC_Clean_Up.ps1) file in this repository.
   - Click "Download" or "Raw" to save the file to your computer.

2. **Run the Script:**
   - Open PowerShell as Administrator.
   - Navigate to the directory where you saved the `PC_Clean_Up.ps1` file.
   - Execute the script by typing:
     ```powershell
     .\PC_Clean_Up.ps1
     ```
